# [Is Escalation Worth It? A Decision-Theoretic Study of Depth in LLM Cascades](https://arxiv.org/abs/2605.06350)

This repository contains public experiment code and cached numerical results for the paper.

The project studies deterministic threshold cascades for large language models. It compares two-model cascades with longer fixed and optimized sequences, single-model baselines, and a diagnostic router across five benchmarks.

The release includes code for response generation, grading, cascade optimization, diagnostics, and figure reproduction. Large raw model responses are not distributed. See the [data notes](DATA.md) and [reproducibility guide](REPRODUCIBILITY.md) for dataset sources, requirements, and run instructions.
