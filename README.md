# [Is Escalation Worth It? On the Depth of LLM Cascades](https://arxiv.org/abs/2605.06350)

This repository contains experiment code and cached numerical results for the paper.

The release includes code for response generation, grading, cascade optimization, diagnostics, and figure reproduction. The [current experiment supplement](reproducibility/README.md) documents the included analyses and run instructions. Large raw model responses are not distributed. See the [data notes](DATA.md) for input requirements.
